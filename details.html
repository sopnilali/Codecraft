Learning paths & curriculum

This page breaks down what each Codecraft track actually covers, how the tracks compare, and where to go for further reading once you've picked a direction.

What you'll study in each track

Every track follows the same shape: fundamentals first, then applied projects, then a specialization. The pace is self-directed, but the order is not — each stage assumes the skills from the one before it.

Web Development

Starts with semantic HTML and the CSS box model, then introduces layout systems like Flexbox and Grid. JavaScript fundamentals follow, covering the DOM and event handling before students touch any framework.

Data Science & AI

Begins with statistics and data cleaning in a spreadsheet or notebook environment, then moves into visualization and basic predictive modeling. The final stage covers how machine learning models are trained and evaluated, without assuming a math degree.

Cybersecurity

Opens with how networks and operating systems actually work, since most security concepts only make sense once you understand what's being protected. Later stages cover common vulnerabilities and the defensive practices used to close them.

Skills you'll build

  • Reading and writing clean, structured code
  • Debugging systematically rather than by guesswork
  • Working comfortably with documentation and official references
  • Explaining technical decisions in plain language

How to get started

  1. Pick one track rather than studying several at once
  2. Finish the fundamentals stage before skipping ahead
  3. Build one small project per stage to confirm understanding
  4. Reach out through the contact page for a personalized plan
